# 竞赛数学学习空间

一个无需安装的本地学习网站，面向大学生数学竞赛备赛。

直接用浏览器打开 `index.html` 即可开始使用。学习进度、答题记录和错题笔记会保存到当前浏览器的本地存储中。

## 包含内容

- 今日学习卡片与完成状态
- 12 周备赛路线
- 每天零点自动轮换的历届真题，支持草稿、答案、完成记录与连续打卡
- 题目关联知识点与标准解题过程
- 历年真题库：按年份、届次、初决赛分类，可搜索和直接打开 PDF
- 第 1—17 届核心题刷题模式：按届次和知识点筛选
- 答案折叠、逐步显示、重点着色与多种解法
- 浏览器本地保存草稿、做题结果、错题集和收藏夹
- 冲奖训练台：准备度、正确率、题库覆盖率与近七日训练量
- 薄弱知识点诊断，可一键进入对应专题训练
- 第 1—17 届知识图谱：逐年考点、核心结论、常用推论和易错提醒
- 可按届次、知识模块或关键词筛选，并标记已掌握专题
- 智能复习：错题优先，并按 1、3、7、14、30 天逐步安排回顾
- 每日 3 题任务、10 分钟限时训练与做题快捷键
- 支持部署为公开网站、添加到手机桌面，并缓存核心页面供离线复习
- 本地错题与思考记录
- 可复制的学习社群推广文案

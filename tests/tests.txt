# Tests

## Test 1 - 完成一道真题并保留记录 [sanity]
Viewport: desktop (1280x800)
Covers: 真题展示、LaTeX 公式、答案折叠、做题记录、本地持久化
Description: 验证核心刷题流程可完成且刷新后统计仍然保留。

Steps:
1. 在“历届真题刷题”中展开答案
2. 点击“我做对了”
3. 刷新页面

Expected: 题目与公式正常显示，顶部正确率和冲奖训练台保留本次记录。

## Test 2 - 智能复习安排错题
Viewport: desktop (1280x800)
Covers: 错题标记、待复习队列、智能复习训练
Description: 验证做错的题会进入复习计划并可立即开始复习。

Steps:
1. 在一道题上点击“加入错题”
2. 回到“冲奖训练台”点击“智能复习”
3. 查看刷题区当前题目

Expected: 待复习数量增加，智能复习打开包含刚才错题的训练。

## Test 3 - 手机端查询历届知识并进入练习
Viewport: mobile (375x667)
Covers: 历届知识图谱、届次筛选、LaTeX 结论、掌握标记、相关真题跳转、响应式布局
Description: 验证手机窄屏下可以学习指定年份的结论并进入对应专题训练。

Steps:
1. 在“历届知识图谱”中选择“第 13 届 · 2021”
2. 搜索“隐函数”，展开结论并点击“标记掌握”
3. 点击“练习相关真题”

Expected: 页面没有横向溢出，只显示第 13 届相关结论，掌握数增加，并跳转到对应专题刷题。

## Test 4 - 限时训练可暂停和结束
Viewport: desktop (1280x800)
Covers: 10 分钟计时、暂停、恢复、结束训练
Description: 验证限时训练的控制按钮按预期工作。

Steps:
1. 点击“10 分钟限时训练”
2. 点击“暂停”，再点击“继续”
3. 点击“结束训练”

Expected: 计时面板出现并能暂停恢复，结束后计时面板消失。

## Test 5 - 空筛选显示安全提示
Viewport: mobile (375x667)
Covers: 收藏筛选、空状态、无记录时的防误导提示
Description: 验证没有收藏题时不会显示错误题目或空白页面。

Steps:
1. 清除当前网站数据
2. 打开“收藏”筛选
3. 查看刷题区域

Expected: 显示当前筛选没有题目的提示，并建议切换全部或先收藏题目。

●●○ 基础巩固
PROBLEM / 001

设函数 f(x) = x2 ln x（x > 0），求 f(x) 在 (0, +∞) 上的最小值。

选择一个答案，检验你的直觉。

本题知识点讲解展开阅读 +

考查核心

导数判别最值

对可导函数，先求驻点（f′(x) = 0），再结合导数符号变化判断增减性。竞赛题里，定义域和端点同样不能漏。

易错提醒
这里 x = 0 不在定义域内；不能只把驻点代回，还要确认它确实给出最小值。

标准思路

  1. 求导：f′(x) = 2xlnx + x = x(2lnx + 1)。
  2. 令 f′(x) = 0。因为 x > 0，所以 lnx = −1/2，即 x = e−1/2。
  3. 当 0 < x < e−1/2 时导数为负；其后为正，故该点为最小值点。
  4. 代回：f(e−1/2) = e−1 · (−1/2) = −1/(2e)。
